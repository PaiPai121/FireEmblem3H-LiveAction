# 战争篇官方参考补齐记录

日期：2026-07-11

## 背景

用户指出 Mercedes 战争篇人像即使重做后仍然不对，核心原因是生成流程没有像学院篇一样强制引用官方战争篇立绘。此前很多战争篇资产只凭文字描述和泛阵营风格生成，容易出现以下问题：

- 年龄被拉老，视频生成继续放大老态。
- 服装只像“战时阵营角色”，不像游戏本人。
- 发型、帽饰、耳饰、职业轮廓等关键识别点丢失。

## 新规则

后续重做任何三学级学生战争篇人像时，必须先检查：

- `assets/characters/<faction>/<Character>/references/official_local/war/fireemblemwiki_main.png`

如果该文件存在，prompt 必须显式引用它，并逐条提取：

- 年龄/脸部年轻度
- 发型轮廓
- 帽饰/头饰
- 主服装色块
- 职业身份道具
- 阵营或个人饰品

未对照官方战争篇参考就直接覆盖 `selected.png`，视为不合格流程。

## 下载来源

通过 Fire Emblem Wiki 页面/图库的 MediaWiki API 获取 `File:Portrait <name> 02 fe16.png` 的 `imageinfo.url`，再保存到本地统一路径。

特殊处理：

- Edelgard / Bernadetta / Claude 的 war portrait 位于 `/Gallery` 页面。
- Lorenz 使用 `Lorenz (Three Houses)` 页面。
- Mercedes 先下载为 `fireemblemwiki_war_portrait.png`，后补统一副本 `fireemblemwiki_main.png`。

# Reed the Flame Shadow Costume Reference Audit

Reference file: `references/wiki_terra_reed_the_flame_shadow_base.png`

Status: `pending_candidate_review`

## Required Checks Before Selection

- Pass/fail: red/orange hair and draconic horn/tail silhouette cues
- Pass/fail: black and red caster outfit with flame-shadow details
- Pass/fail: staff/flame-medic silhouette when visible
- Pass/fail: reserved posture, not aggressive warrior grin
- Pass/fail: warm ember lighting can support but must not hide costume
- Pass/fail: face is distinct from all existing selected operators.
- Pass/fail: skin/hair/fabric read as real, not wax/plastic.
- Pass/fail: hands, visible props, and costume structure are not visibly broken.
- Pass/fail: the asset can be used in later video prompts without explaining around identity drift.

## Blockers

- Block if the output uses a different skin as its costume authority.
- Block if the generated image is merely attractive but not recognizably Reed the Flame Shadow.
- Block if the image hides the character-defining costume or prop silhouette.

Every future Nian candidate must be checked against these points before it may reach `selected`:

| Requirement | Required From Base Reference | V8 | V9 | V10 |

| Red horns | red horns readable and placed correctly | pass | pass | pass |
| Red crop top | red bandeau/crop top remains visible, not replaced by black director top | fail | fail | pass |
| Open light coat | light gray-white open long coat with red trim | partial | fail | pass |
| Short gray lower outfit | shorts/skirt-like lower layer close to base reference | fail | fail | pass |

| Footwear | practical sneakers/boots from base reference, not high-heel director boots | fail | fail | pass |
| Tail | visible dragon tail with warm red/orange end when full-body | pass | pass | pass |
| Sui/craft prop silhouette | heavy craft/weapon props can be simplified but not replaced by generic set dressing | fail | fail | monitor |
| BTS director role | established by props/environment only, without changing costume authority | partial | partial | pass |
| Real-actor wardrobe realism | practical production-set photo, not poster/cosplay-only polish | fail | fail | pass |
| Overall recognition | recognizable as base Nian before reading filename | fail | fail | pass |

## Audit Rule

Partial surface-token matches are not enough. A candidate must preserve the base outfit's silhouette and garment construction before it can be treated as a usable production candidate. Director tools are additive props, not costume authority.

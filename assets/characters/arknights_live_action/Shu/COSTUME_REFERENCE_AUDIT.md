- Pass/fail: green, cream, earth, and harvest-color outfit language
- Pass/fail: agricultural/grain/field divinity impression rather than palace-only glamour
- Pass/fail: soft but capable posture
- Pass/fail: organic fabric textures, embroidered details, grounded warmth
- Pass/fail: face is distinct from all existing selected operators.
- Pass/fail: skin/hair/fabric read as real, not wax/plastic.
- Pass/fail: hands, visible props, and costume structure are not visibly broken.

## Blockers

- Block if the output uses a different skin as its costume authority.
- Block if the generated image is merely attractive but not recognizably Shu.

# Female Byleth Official Sources

No local official reference image file was fetched in the original asset pass. This is now a fidelity blocker for any shot that claims canon-accurate Female Byleth clothing.

Use this file to record official female Byleth reference provenance if a source image is later added under:

`assets/characters/protagonist/BylethFemale/references/official_local/professor/`

External reference targets identified for the required local official reference pack:

- Fire Emblem Wiki / Fandom gallery, `Byleth/Gallery`, includes official artwork of Female Byleth from Fire Emblem: Three Houses.
- Fire Emblem Wiki / Fandom category `Three Houses Artwork`, lists `Artwork Byleth F.png` and `FByleth Concept Art.png`.
- Byleth character page notes Byleth serves as a Garreg Mach professor and wields the Sword of the Creator.

Status on 2026-08-05: external pages were identified, but no local official image was successfully fetched into this repo during this pass. Before final visual approval, add a local official-art reference image and update this file with exact source URL, download path, and provenance.

Updated clothing lock:

- Teal-blue medium hair and green eyes.
- Black short capelet / shoulder mantle, not a floor-length robe.
- High black collar.
- Black cropped upper garment with a visible midriff gap in the official design.
- Gold crest/star chest ornament.
- Silver forearm armor / bracers.
- Black shorts or short skirt panels over patterned black tights.
- Single knee guard / asymmetric leg armor.
- Tall black boots.
- Belts, harnesses, dagger/sword carry details.
- Sword of the Creator when using the canonical weapon; for the Kakeya training lesson, a plain wooden practice sword may replace the weapon only as a deliberate classroom prop, not as a costume redesign.

Reject if:

- The outfit becomes a generic black long coat, nun robe, wizard robe, modern leather coat, normal teacher coat, student uniform, or generic fantasy black dress.
- The short capelet, high collar, gold chest ornament, forearm armor, patterned tights, knee guard, and boot silhouette all disappear.
- The official cropped/short outfit structure is “corrected” into a fully closed long robe.

# 贝雷丝 / 女贝老师（Female Byleth）角色描述

16 岁、冷静、带神秘感的佣兵出身年轻教师/主角。她是与现有男贝雷特老师并列的女贝老师视觉资产，不替换 `assets/characters/protagonist/Byleth`。

- 外观：青黑偏蓝的中长发，绿色眼睛，五官应读作 16 岁漂亮女孩但不过幼：小脸、柔和但不圆的脸颊、明亮冷静的眼睛、轻而有一点线条的下颌、皮肤干净，神情克制、少情绪外露。
- 服装：应读作学院篇女贝雷丝的官方服装结构，而不是普通黑色长外套。核心包括黑色短披肩/肩甲披风、高领黑色短上衣、胸前金色纹章饰件、露出上腹的短衣摆、银色护臂、黑色短裤或裙片、花纹黑丝袜、单侧膝甲、黑色长靴、腰带与剑/短刀挂具。真人化时可以控制暴露度，但不能把上半身改成全封闭黑袍、普通女教师长外套或现代皮衣。
- 气质：沉静、敏锐、距离感、隐藏力量；像 16 岁的冷感天才少女教师/佣兵主角，不像普通学生、年长导师、成年战士或幼态娃娃脸。
- 武器锁：主角资产与关键剧情可使用天帝之剑。下游生成必须以 `assets/props/shared/sword_of_creator/selected.png` 为武器权威：黑金异形钩状护手、护手中心空心圆环、长而窄的单一骨节链刃、一侧有不规则齿状/节段边缘、深色中脊；常规静止剑形态优先，避免无意切成鞭形态。
- 避免：不要中年化，不要二十多岁成人脸，不要成熟硬朗的成人战士脸，不要低龄娃娃脸，不要圆脸或甜偶像脸，不要做成性感法师、普通黑袍女巫、全封闭黑色长袍、现代皮衣、普通女教师长外套、贵族礼服或学生制服路人；天帝之剑不要变成普通木剑、普通钢剑、红宝石发光剑、双轨双刃剑或夸张巨剑。

# 天帝之剑 / Sword of the Creator Prop Lock

用途：Female Byleth / Byleth 的主角圣遗物武器参考。此资产用于替代泛用骨剑、金色奇幻大剑或木剑。

## Visual Lock

- 长窄直剑轮廓，不能宽厚。
- 剑身为旧金/骨白金属质感，不能大面积红宝石或红色光条。
- 剑身有脊椎/骨节式分段结构。
- 单侧有不规则齿/突起。
- 剑身中线有深色槽或黑色内脊。
- 护手为黑金 hooked shape，中心有空心圆环/纹章槽。
- 短握柄、小型柄头，整体像古代圣遗物，不像普通钢剑或巴洛克装饰剑。
- 默认普通剑形态；鞭形态必须由镜头单独指定。

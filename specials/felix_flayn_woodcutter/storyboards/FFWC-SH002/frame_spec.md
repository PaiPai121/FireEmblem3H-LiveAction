# FFWC-SH002 Frame Spec

## Purpose

Turn Flayn's praise into a practical question.

## Start Frame

Felix looks unimpressed by praise; Flayn remains bright and polite.

## Key Frame

Flayn gestures toward the unseen woodpile.

## End Frame

Felix notices where this is going.

## Identity Locks

Flayn sincere, not scheming. Felix blunt, not cruel.

## Reject If

Reject if Flayn looks manipulative, if Felix smiles warmly, or if subtitles appear.

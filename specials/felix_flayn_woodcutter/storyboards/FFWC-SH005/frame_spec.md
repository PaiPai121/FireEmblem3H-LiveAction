# FFWC-SH005 Frame Spec

## Purpose

Land the "woodcutter master" title gag.

## Start Frame

Flayn admires the neat split wood.

## Key Frame

Flayn beams at Felix and names him the monastery's finest woodcutter.

## End Frame

Felix turns away, objecting, with a tiny almost-hidden pleased expression.

## Identity Locks

Felix satisfaction must be subtle. Flayn is delighted, not teasing cruelly.

## Reject If

Reject if Felix grins broadly, if Flayn laughs at him, or if the ending becomes romantic.

# FFWC-SH004 Frame Spec

## Purpose

Show Felix turning a chore into elite sword discipline.

## Start Frame

Felix accepts once; Flayn has brought the full pile closer.

## Key Frame

Felix cuts a log with precise downward sword motion, safe distance from Flayn.

## End Frame

Neat split wood pile; Felix composed; Flayn delighted.

## Identity Locks

No enemies. Logs are the only target. Felix remains serious.

## Reject If

Reject if action becomes combat, if Flayn stands too close to the blade, or if wood pieces explode unrealistically.

# FFWC-SH003 Frame Spec

## Purpose

Reveal the woodpile and trigger Felix's pride.

## Start Frame

Felix sees a small pile of unsplit logs near the training ground edge.

## Key Frame

Felix says he is not a firewood worker.

## End Frame

Flayn innocently wonders whether the task is difficult even for him.

## Identity Locks

Felix proud and contained. Flayn gentle and sincere.

## Reject If

Reject if Felix yells, if Flayn mocks him, or if wood contains readable labels.

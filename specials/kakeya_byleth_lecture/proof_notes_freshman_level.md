# 女贝老师二维挂谷：大一高数版证明备注

这份备注给视频和网页审查用。目标不是写严肃论文，而是保证科普台词里的每个关键结论都有可追踪的证明桥。

## 0. 先分清两个版本

视频开头讲的是“针在区域里连续转动”。Perron 树最直接证明的是较弱但核心的版本：每个方向都能在集合里找到一条完整单位线段。

这两者的连接方式是：先构造方向覆盖的细碎集合，再用极窄的连接走廊把不同位置的动作接起来。走廊宽度可以任意小，所以总面积只增加一个可控制的小量。于是对“任意 epsilon 大小的正面积区域”这个结论，两种说法可以接上。

视频里必须避免一句话把“有每个方向的线段”直接偷换成“已经连续转完”。需要出现“窄走廊补连续转动”的桥句。

## 1. 三尖内摆线为什么是候选

三尖内摆线不是最终答案，它只是早期很自然、很漂亮的候选。

把三尖内摆线的尺度记作 `a`。经典几何事实是：它的一族可用切线弦长度恒为 `4a`。直观上，切点沿三尖曲线走一圈，切线方向也连续转过一圈，所以方向不会中途漏掉。

要放下一根长度为 1 的针，就令

```text
4a = 1
a = 1/4
```

三尖内摆线的面积可以由参数曲线面积公式计算：

```text
A = 1/2 ∫(x dy - y dx) = 2πa^2
```

代入 `a = 1/4`：

```text
A = 2π(1/4)^2 = π/8
```

所以三尖内摆线的作用是证明“面积不必像固定圆盘那么大”。但它没有证明“不能更小”。

## 2. 凸区域为什么是高为 1 的等边三角形

先加一个额外限制：区域必须是凸的。凸的意思是区域里任意两点连线都不能跑到外面。

在凸世界里，结论是一个定理：能容纳所有方向单位线段的凸区域，面积至少是高为 1 的等边三角形面积；而这个等边三角形又确实能容纳所有方向的单位线段。因此它同时给出上界和下界。

面积计算很简单。等边三角形高为 1，边长 `s` 满足

```text
(s/2)^2 + 1^2 = s^2
s = 2/sqrt(3)
```

面积为

```text
A = s * 1 / 2 = 1/sqrt(3)
```

视频中可以把严格下界称为“凸情形定理”，只给直观图：凸性会把碎片之间的空隙一起包进去，所以不能像非凸集合那样反复复用空间。

## 3. Perron 树为什么能把面积压到任意小

一个高而薄的三角形可以保存一段连续方向：从顶点到底边不同点的线段，对应一段斜率。

Perron 操作分三步：

1. 切分：把底边分成许多小段，每个小三角形负责一小段方向。方向没有删除，只是分配给不同碎片。
2. 平移：把小三角形移动到更容易重叠的位置。平移不会改变线段方向。
3. 重叠：碎片大面积重叠后，并集面积变小；但每个方向仍然能在某个碎片里找到单位线段。

定量直觉是：切得越细，单个碎片越薄，越容易被平移到高度重叠的位置。每一轮可以让并集面积按预先安排的比例下降，同时方向尺仍无缺口。给定任意 `epsilon > 0`，选择足够多轮迭代，就能让总面积小于 `epsilon`。

这就是“没有最小正面积”的反直觉之处：不是找到一个最小形状，而是任何正数门槛都还能继续往下压。

## 4. 面积为 0 不是“不存在”

线段本身长度为 1，但平面面积为 0。类似地，挂谷集可以面积为 0，却仍然包含每个方向的单位线段。

视频里不能把“面积为 0”画成完全消失。正确画法是：集合仍可见为很多细线、细纹或极限结构，只是没有二维面积。

## 5. δ 管估计为什么出现

真实线段面积为 0，不方便直接估计。数学家常把线段加粗成宽度为 `δ` 的细管。

两根宽度 `δ` 的管以夹角 `α` 相交时，重叠区域像一个细长平行四边形：

```text
交叠长度 ≈ δ / sin α
交叠宽度 ≈ δ
交叠面积 ≈ δ^2 / sin α
```

当角度小但不为 0 时，`sin α` 和 `α` 同量级，所以常写成

```text
|T_i ∩ T_j| <= C δ^2 / α
```

这个估计把“方向差”与“能重叠多少面积”连起来，是后面最大函数、波包、组合几何等影响的共同入口。

## 6. 维数为什么还能是 2

可以先用网格计数理解维数。网格宽度为 `δ` 时：

```text
普通曲线大约需要 1/δ 个小格子覆盖
真正二维区域大约需要 1/δ^2 个小格子覆盖
```

二维挂谷集的反直觉结论是：它的面积可以为 0，但因为它包含所有方向的单位线段，尺度复杂度不能退化成普通曲线。现代二维结论是它的维数必须为 2。

视频结尾的意义应落在这里：挂谷问题教我们研究“许多方向的细长结构如何重叠”，而不是泛泛地说“生活中要节省空间”。

# 二维挂谷视频提示词时长审查

Status: `retimed_monitor_required`
Date: 2026-08-02

## 结论

原始总时长：492 秒。修订后总时长：303 秒（05:03）。

本次发现的问题不是“少数镜头偏长”，而是全包时长策略不干净：很多一句话或简单图解镜头给到 14-20 秒，会让一次性视频生成出现尾部硬停、身份漂移、公式闪烁和无意义镜头运动。

修订策略：

- 普通讲解/互动镜头：7-10 秒。
- 核心证明镜头：11-12 秒。
- 简短概念句、定理句、结尾卡：5-7 秒。
- 全片不再保留 13-20 秒长尾镜头。

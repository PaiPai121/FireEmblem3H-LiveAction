# 分镜规格：SH028

阶段：真实帧锁定视频提示词包
状态：真实帧已生成，提示词已就绪
依赖：女贝老师二维挂谷分镜表
剧情节点：维数直觉
成片作用：解释面积可以消失，但尺度复杂度没有消失。
时长目标：11 秒
地点：抽象粉笔网格
可见角色：仅图解

身份锁：
- 女贝老师只使用女版教授形象，不使用男贝。
- 女贝老师参考：assets/characters/protagonist/BylethFemale/professor/selected.png。
- 需要全身姿态、手套或持剑动作时，使用：assets/characters/protagonist/BylethFemale/weapon_fullbody/selected.png。
- 可见学生阵容锁定为艾黛尔、莉丝缇亚、梅尔赛德斯，不得替换成其他学生或普通学生。

资产引用：
- 图解或道具镜头，不需要角色资产。

起始帧意图：
粗网格覆盖淡蓝多方向集合，占用若干格。

关键帧意图：
网格变细，命中的格子仍在二维范围内铺开。

结束帧意图：
画面旁出现“不是一条普通曲线”的简短标记。

摄影机：
网格俯视缩放，像显微镜推进。

调度：
网格尺度变小，左侧普通曲线约击中 1/δ 个格子，右侧多方向细纹仍在二维范围内击中接近 1/δ^2 个格子。

画面方向：
镜头向网格中心推进，集合不消失。

数学图形锁：
- 零面积不是不存在；δ 管图解必须显示 δ 宽度、α 夹角、金色重叠区域，并在二维最终结论中显示维数等于 2。

动作峰值：
细网格下多方向结构仍横竖铺开的瞬间。

中文台词 / 音频锚点：
女贝老师: 维数先看盖住它要多少小格子；这种多方向集合不像普通曲线那样省格子。

剪入：
从估计式右侧的图形像素化进网格。

剪出：
网格整理成黑板上二维定理。

连续性要求：
- 上一镜头: SH027 （关键估计）.
- 下一镜头: SH029 （二维定理）.
- 保持上方规定的画面方向和视觉主体交接。
- 不得添加未计划的指定学生；除非已有批准资产，学生台词只使用画外音或肩部剪影。

运动风险：
- 豪斯多夫术语出现过突兀，则需要降低门槛。
- AI 视频可能过度装饰数学图形；必须保持几何关系、端点标记、δ/α 标签、并集/重叠关系清楚可读。
- 如果女贝老师可见，必须监看跨帧和相邻镜头中的身份漂移。

拒绝条件：
- 豪斯多夫术语出现过突兀，则需要降低门槛。
- 起始帧、关键帧、结束帧没有形成规定动作链，则拒绝。
- 镜头运动遮住动作峰值，或反转既定画面方向，则拒绝。
- δ、α、重叠、零面积澄清或维数等于 2 的结论不可见或错误

# 分镜规格：SH023

镜头编号：SH023
阶段：真实帧锁定视频提示词包
状态：真实帧已生成，提示词已就绪
依赖：女贝老师二维挂谷分镜表
剧情节点：经典结论
成片作用：给出经典结论：原问题没有最小正面积答案。
时长目标：12 秒
地点：加尔古·玛库教室
可见角色：女贝老师

身份锁：
- 女贝老师只使用女版教授形象，不使用男贝。
- 女贝老师参考：assets/characters/protagonist/BylethFemale/professor/selected.png。
- 需要全身姿态、手套或持剑动作时，使用：assets/characters/protagonist/BylethFemale/weapon_fullbody/selected.png。
- 可见学生阵容锁定为艾黛尔、莉丝缇亚、梅尔赛德斯，不得替换成其他学生或普通学生。

资产引用：
- assets/characters/protagonist/BylethFemale/professor/selected.png
- assets/characters/protagonist/BylethFemale/weapon_fullbody/selected.png

起始帧意图：
黑板上同时有 三尖内摆线、凸三角形、佩龙树 树三个小图。

关键帧意图：
前两个图淡下去，佩龙树 树放大，女贝老师说出没有最小正答案。

结束帧意图：
黑板只剩“不存在最小正面积”的粉笔结论。

摄影机：
缓慢推近中景，人物与结论同框。

调度：
三尖内摆线 和三角形淡出，佩龙树 树保持；女贝老师侧身让出结论；极细连接走廊淡出显示面积可忽略。

画面方向：
女贝老师站画面左，结论在画面右，避免遮挡。

数学图形锁：
- 佩龙树 证明必须保持方向覆盖可见：切分分配方向区间，平移不旋转，重叠缩小并集面积且不删除方向。

动作峰值：
佩龙树 树独自留下的瞬间。

中文台词 / 音频锚点：
女贝老师: 所以，原来的最小面积问题，没有最小正答案。小到任意正数以下，不是等于不存在。

剪入：
从 SH022 树状碎片匹配切到黑板。

剪出：
结论里的“面积”二字切到零面积提示。

连续性要求：
- 上一镜头: SH022 （迭代加速）.
- 下一镜头: SH024 （零面积澄清）.
- 保持上方规定的画面方向和视觉主体交接。
- 不得添加未计划的指定学生；除非已有批准资产，学生台词只使用画外音或肩部剪影。

运动风险：
- 必须保持准确措辞。
- AI 视频可能过度装饰数学图形；必须保持几何关系、端点标记、δ/α 标签、并集/重叠关系清楚可读。
- 如果女贝老师可见，必须监看跨帧和相邻镜头中的身份漂移。

拒绝条件：
- 必须保持准确措辞。
- 起始帧、关键帧、结束帧没有形成规定动作链，则拒绝。
- 镜头运动遮住动作峰值，或反转既定画面方向，则拒绝。
- 女贝老师变成男贝、成年导师、普通魔女或普通学生，则拒绝。
- 佩龙树的切分、平移、重叠或方向保持逻辑被画错，则拒绝。

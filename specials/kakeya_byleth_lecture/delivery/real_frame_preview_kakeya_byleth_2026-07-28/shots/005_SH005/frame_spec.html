# 分镜规格：SH005

镜头编号：SH005
阶段：真实帧锁定视频提示词包
状态：真实帧已生成，提示词已就绪
依赖：女贝老师二维挂谷分镜表
剧情节点：方向覆盖
成片作用：把口语问题翻译成数学条件：每个方向都要有一条完整单位线段。
时长目标：8 秒
地点：教室图解板
可见角色：女贝老师作为小侧影; 图解为主

身份锁：
- 女贝老师只使用女版教授形象，不使用男贝。
- 女贝老师参考：assets/characters/protagonist/BylethFemale/professor/selected.png。
- 需要全身姿态、手套或持剑动作时，使用：assets/characters/protagonist/BylethFemale/weapon_fullbody/selected.png。
- 可见学生阵容锁定为艾黛尔、莉丝缇亚、梅尔赛德斯，不得替换成其他学生或普通学生。

资产引用：
- assets/characters/protagonist/BylethFemale/professor/selected.png
- assets/characters/protagonist/BylethFemale/weapon_fullbody/selected.png

起始帧意图：
黑板上只有一条红色单位线段和端点标尺。

关键帧意图：
绿色幽灵线段在不同角度依次出现，每条都保留完整端点。

结束帧意图：
扇面稳定为稀疏但连续方向族，避免堆成杂乱光团。

摄影机：
教师视角宽镜，黑板和讲桌同框。

调度：
绿色幽灵线段从少到多出现，最终覆盖从 0 到 180 度的方向族。

画面方向：
方向从左下到右上逐步展开。

数学图形锁：
- 一单位线段必须清楚显示长度为 1 且有两个端点；条件是覆盖所有方向，不是固定中心，除非画面明确把固定中心作为被否定的直觉。

动作峰值：
最后一条缺失方向被补齐的瞬间。

中文台词 / 音频锚点：
女贝老师: 真正的条件是：每个方向，都要有一条完整的一单位线段。

剪入：
从 SH004 的可移动中心箭头接入。

剪出：
绿色扇面收束成三尖曲线的第一笔。

连续性要求：
- 上一镜头: SH004 （规则澄清）.
- 下一镜头: SH006 （三尖内摆线候选）.
- 保持上方规定的画面方向和视觉主体交接。
- 不得添加未计划的指定学生；除非已有批准资产，学生台词只使用画外音或肩部剪影。

运动风险：
- 幽灵剑过多导致画面拥挤，则拒绝。
- AI 视频可能过度装饰数学图形；必须保持几何关系、端点标记、δ/α 标签、并集/重叠关系清楚可读。
- 如果女贝老师可见，必须监看跨帧和相邻镜头中的身份漂移。

拒绝条件：
- 幽灵剑过多导致画面拥挤，则拒绝。
- 起始帧、关键帧、结束帧没有形成规定动作链，则拒绝。
- 镜头运动遮住动作峰值，或反转既定画面方向，则拒绝。
- 女贝老师变成男贝、成年导师、普通魔女或普通学生，则拒绝。
- 一单位线段失去可见端点，或木剑变成没有长度含义的装饰剑，则拒绝。

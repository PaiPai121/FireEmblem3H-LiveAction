# 分镜规格：SH012

镜头编号：SH012
阶段：真实帧锁定视频提示词包
状态：真实帧已生成，提示词已就绪
依赖：女贝老师二维挂谷分镜表
剧情节点：凸性定义
成片作用：用两点连线说明什么叫凸，降低理解门槛。
时长目标：7 秒
地点：图解板
可见角色：仅图解; 贝老师 指示手可选

身份锁：
- 女贝老师只使用女版教授形象，不使用男贝。
- 女贝老师参考：assets/characters/protagonist/BylethFemale/professor/selected.png。
- 需要全身姿态、手套或持剑动作时，使用：assets/characters/protagonist/BylethFemale/weapon_fullbody/selected.png。
- 可见学生阵容锁定为艾黛尔、莉丝缇亚、梅尔赛德斯，不得替换成其他学生或普通学生。

资产引用：
- assets/characters/protagonist/BylethFemale/professor/selected.png
- assets/characters/protagonist/BylethFemale/weapon_fullbody/selected.png

起始帧意图：
左右两个区域各有两点，连线尚未出现。

关键帧意图：
连线出现：左侧全绿，右侧穿出区域部分变红。

结束帧意图：
左图打勾，右图被轻划，观众知道限制含义。

摄影机：
干净二分图近景，板书符号极少。

调度：
左侧连线全在区域内，右侧连线穿出凹口，女贝老师用粉笔点亮差别。

画面方向：
读图从左到右，绿色通过、红色失败。

数学图形锁：
- 凸三角形只是在凸区域限制下的最优解；等边三角形高度为 1，边长为 2/sqrt(3)，面积为 1/sqrt(3)。

动作峰值：
右侧连线穿出凹口的红段亮起。

中文台词 / 音频锚点：
女贝老师: 凸，就是两点之间的路不离开区域。

剪入：
从绳索凹口消失切入。

剪出：
左侧凸形变形为等边三角形。

连续性要求：
- 上一镜头: SH011 （切换到凸区域）.
- 下一镜头: SH013 （Triangle can turn）.
- 保持上方规定的画面方向和视觉主体交接。
- 不得添加未计划的指定学生；除非已有批准资产，学生台词只使用画外音或肩部剪影。

运动风险：
- 内容基础但必要，不能因为基础而删掉。
- AI 视频可能过度装饰数学图形；必须保持几何关系、端点标记、δ/α 标签、并集/重叠关系清楚可读。
- 如果女贝老师可见，必须监看跨帧和相邻镜头中的身份漂移。

拒绝条件：
- 内容基础但必要，不能因为基础而删掉。
- 起始帧、关键帧、结束帧没有形成规定动作链，则拒绝。
- 镜头运动遮住动作峰值，或反转既定画面方向，则拒绝。
- 女贝老师变成男贝、成年导师、普通魔女或普通学生，则拒绝。
- 等边三角形被暗示为非凸原问题的解，则拒绝。

# 分镜规格：SH024

镜头编号：SH024
阶段：真实帧锁定视频提示词包
状态：真实帧已生成，提示词已就绪
依赖：女贝老师二维挂谷分镜表
剧情节点：零面积澄清
成片作用：防误解：面积为零不是不存在。
时长目标：7 秒
地点：干净图解空间
可见角色：仅图解

身份锁：
- 女贝老师只使用女版教授形象，不使用男贝。
- 女贝老师参考：assets/characters/protagonist/BylethFemale/professor/selected.png。
- 需要全身姿态、手套或持剑动作时，使用：assets/characters/protagonist/BylethFemale/weapon_fullbody/selected.png。
- 可见学生阵容锁定为艾黛尔、莉丝缇亚、梅尔赛德斯，不得替换成其他学生或普通学生。

资产引用：
- 图解或道具镜头，不需要角色资产。

起始帧意图：
白色羊皮纸上只有一条黑线段，旁边标长度。

关键帧意图：
面积填色尝试出现又消失，只留下“平面面积 0”的小标记。

结束帧意图：
多方向细纹集合出现，强调可见但面积可为零。

摄影机：
极简图解近景，干净留白。

调度：
一条线段显示长度刻度但面积填色为无；随后多方向集合以淡蓝细纹出现。

画面方向：
单线段从左侧过渡到右侧多方向集合。

数学图形锁：
- 零面积不是不存在；δ 管图解必须显示 δ 宽度、α 夹角、金色重叠区域，并在二维最终结论中显示维数等于 2。

动作峰值：
线段仍清晰存在而面积标记为 0 的瞬间。

中文台词 / 音频锚点：
女贝老师: 面积为零，不是不存在。线段也没有平面面积。

剪入：
从黑板结论中“面积”切入。

剪出：
线段变粗成 δ 管。

连续性要求：
- 上一镜头: SH023 （经典结论）.
- 下一镜头: SH025 （δ 管方法）.
- 保持上方规定的画面方向和视觉主体交接。
- 不得添加未计划的指定学生；除非已有批准资产，学生台词只使用画外音或肩部剪影。

运动风险：
- 不得暗示真实旋转区域本身直接为零。
- AI 视频可能过度装饰数学图形；必须保持几何关系、端点标记、δ/α 标签、并集/重叠关系清楚可读。
- 如果女贝老师可见，必须监看跨帧和相邻镜头中的身份漂移。

拒绝条件：
- 不得暗示真实旋转区域本身直接为零。
- 起始帧、关键帧、结束帧没有形成规定动作链，则拒绝。
- 镜头运动遮住动作峰值，或反转既定画面方向，则拒绝。
- δ、α、重叠、零面积澄清或维数等于 2 的结论不可见或错误

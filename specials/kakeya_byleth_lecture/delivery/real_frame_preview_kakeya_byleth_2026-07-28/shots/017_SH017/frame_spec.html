# 分镜规格：SH017

镜头编号：SH017
阶段：真实帧锁定视频提示词包
状态：真实帧已生成，提示词已就绪
依赖：女贝老师二维挂谷分镜表
剧情节点：切分步骤
成片作用：第一步切分：把方向任务分给更细的小三角形。
时长目标：8 秒
地点：沙盘图解
可见角色：仅图解

身份锁：
- 女贝老师只使用女版教授形象，不使用男贝。
- 女贝老师参考：assets/characters/protagonist/BylethFemale/professor/selected.png。
- 需要全身姿态、手套或持剑动作时，使用：assets/characters/protagonist/BylethFemale/weapon_fullbody/selected.png。
- 可见学生阵容锁定为艾黛尔、莉丝缇亚、梅尔赛德斯，不得替换成其他学生或普通学生。

资产引用：
- 图解或道具镜头，不需要角色资产。

起始帧意图：
完整大三角形和绿色方向扇保持。

关键帧意图：
底边切成多个小区间，细三角形轮廓同时出现。

结束帧意图：
小三角形略分离，每个区间仍有绿色方向线。

摄影机：
正上方，轻微放大底边。

调度：
底边被等分，小三角形沿切线略微分开，但每个仍从顶点指向自己的底边区间。

画面方向：
底边从左到右被切分，顶点不移动。

数学图形锁：
- 佩龙树 证明必须保持方向覆盖可见：切分分配方向区间，平移不旋转，重叠缩小并集面积且不删除方向。

动作峰值：
所有小区间都有对应绿色线的瞬间。

中文台词 / 音频锚点：
女贝老师: 第一步，切分。每块只负责一小段方向。

剪入：
从 SH016 底边准备切分处接入。

剪出：
切到小三角形水平滑动。

连续性要求：
- 上一镜头: SH016 （佩龙树准备）.
- 下一镜头: SH018 （平移步骤）.
- 保持上方规定的画面方向和视觉主体交接。
- 不得添加未计划的指定学生；除非已有批准资产，学生台词只使用画外音或肩部剪影。

运动风险：
- 切分不能看起来像删除方向。
- AI 视频可能过度装饰数学图形；必须保持几何关系、端点标记、δ/α 标签、并集/重叠关系清楚可读。
- 如果女贝老师可见，必须监看跨帧和相邻镜头中的身份漂移。

拒绝条件：
- 切分不能看起来像删除方向。
- 起始帧、关键帧、结束帧没有形成规定动作链，则拒绝。
- 镜头运动遮住动作峰值，或反转既定画面方向，则拒绝。
- 佩龙树的切分、平移、重叠或方向保持逻辑被画错，则拒绝。

# 分镜规格：SH031

镜头编号：SH031
阶段：真实帧锁定视频提示词包
状态：真实帧已生成，提示词已就绪
依赖：女贝老师二维挂谷分镜表
剧情节点：最大函数与波包
成片作用：把细管重叠连接到最大函数和波包等具体数学对象。
时长目标：10 秒
地点：教室黑板
可见角色：女贝老师可选指示手

身份锁：
- 女贝老师只使用女版教授形象，不使用男贝。
- 女贝老师参考：assets/characters/protagonist/BylethFemale/professor/selected.png。
- 需要全身姿态、手套或持剑动作时，使用：assets/characters/protagonist/BylethFemale/weapon_fullbody/selected.png。
- 可见学生阵容锁定为艾黛尔、莉丝缇亚、梅尔赛德斯，不得替换成其他学生或普通学生。

资产引用：
- assets/characters/protagonist/BylethFemale/professor/selected.png
- assets/characters/protagonist/BylethFemale/weapon_fullbody/selected.png

起始帧意图：
黑板有三个空框和淡绿色方向线。

关键帧意图：
三个关键词与小图同时配对出现，女贝老师用木尺逐一点过。

结束帧意图：
小图留下，文字退淡，过渡到题名揭示。

摄影机：
可读黑板插图，固定近景。

调度：
每个英文术语旁都有小图：矩形平均、波束射线、管重叠，文字不超过三词。

画面方向：
木尺从左到右点过三项。

数学图形锁：
- 影响部分必须绑定证明机制：细管重叠、最大平均、波包、挂谷最大函数直觉和组合几何；不要松散生活化说法。

动作峰值：
波包射线 图和 细管 重叠 图同时亮起的一刻。

中文台词 / 音频锚点：
女贝老师: 调和分析和波动问题里，也会遇到这样的细管。

剪入：
从三联图中格/右格拉近。

剪出：
黑板清空，只留下标题位置。

连续性要求：
- 上一镜头: SH030 （数学影响）.
- 下一镜头: SH032 （名称揭示）.
- 保持上方规定的画面方向和视觉主体交接。
- 不得添加未计划的指定学生；除非已有批准资产，学生台词只使用画外音或肩部剪影。

运动风险：
- 术语不解释会显得过于学术。
- AI 视频可能过度装饰数学图形；必须保持几何关系、端点标记、δ/α 标签、并集/重叠关系清楚可读。
- 如果女贝老师可见，必须监看跨帧和相邻镜头中的身份漂移。

拒绝条件：
- 术语不解释会显得过于学术。
- 起始帧、关键帧、结束帧没有形成规定动作链，则拒绝。
- 镜头运动遮住动作峰值，或反转既定画面方向，则拒绝。
- 女贝老师变成男贝、成年导师、普通魔女或普通学生，则拒绝。
- 影响部分被讲成松散生活比喻，而不是证明导出的细管、波包、最大平均结构，则拒绝。

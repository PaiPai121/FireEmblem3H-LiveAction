# SIBH-SH001 Frame Spec

## Shot Purpose

Use Nian as the one-shot cameo trigger: Sylvain is caught mid-flirt before the support confrontation begins.

## Start Frame

Nian crosses the Garreg Mach corridor or courtyard threshold with an amused, self-possessed look; Sylvain notices her.

## Key Frame

Sylvain steps into a polite, over-smooth compliment. Nian raises an amused eyebrow, not offended.

## End Frame

Nian is already exiting; Sylvain hears Ingrid offscreen and turns.

## Identity Locks

Sylvain stays academy-age and charming but not predatory. Nian keeps the v5 white-haired red-horned cameo identity. Nian appears only in this shot.

## Reject If

Reject if Nian becomes a third lead, if Sylvain leers, if readable tablet text appears, or if modern props dominate the Fire Emblem setting.

# SIBH-SH004 Frame Spec

## Shot Purpose

Stack the scarecrow and noble-apology examples while Sylvain visibly shrinks.

## Start Frame

Sylvain quietly asks Ingrid to lower her voice because people are watching.

## Key Frame

Ingrid names the scarecrow incident; Sylvain tries to explain it away.

## End Frame

Ingrid adds that she apologized to an angry noble; Sylvain backs toward the wall.

## Identity Locks

Ingrid stays youthful and responsible; Sylvain stays embarrassed and playful rather than threatening.

## Reject If

Reject if Ingrid yells, if Sylvain looks predatory or hostile, if Nian returns, or if background students become the main subject.

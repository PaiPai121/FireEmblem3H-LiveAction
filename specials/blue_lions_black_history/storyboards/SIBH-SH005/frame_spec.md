# SIBH-SH005 Frame Spec

## Shot Purpose

End with Ingrid's corrective support beat: this cannot be only today's defeat; Sylvain needs to change now.

## Start Frame

Sylvain admits defeat for today; Ingrid stays composed and refuses to let him dodge.

## Key Frame

Ingrid delivers the actual correction: start changing now.

## End Frame

Sylvain gives a small failed recovery smile and says he will try.

## Identity Locks

Ingrid composed, youthful, and precise; Sylvain sheepish but not crushed. Both remain academy-age Blue Lions students.

## Reject If

Reject if Ingrid laughs at him, if Sylvain looks devastated, if Nian returns, or if the ending turns romantic.

# SIBH-SH002 Frame Spec

## Shot Purpose

Remove Nian from the scene and pivot into the Sylvain/Ingrid C-support confrontation.

## Start Frame

Ingrid enters from screen-left; Nian is gone; Sylvain turns from the failed approach.

## Key Frame

Ingrid gives a tired dry look while Sylvain begins a harmless-kindness explanation.

## End Frame

Ingrid asks how many times she has had to apologize for him.

## Identity Locks

Ingrid uses the new youthful academy reference: 17-18, soft cheeks, light makeup, disciplined but not mature. Sylvain remains playful and embarrassed.

## Reject If

Reject if Ingrid looks jealous, if Nian is still visible, if Sylvain flirts with Ingrid, or if either character ages up.

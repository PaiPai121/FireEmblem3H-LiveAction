# BTS-SH003 Frame Spec

## Shot Purpose

Ground the special as a production by showing prop and wardrobe maintenance.

## Start Frame

Foreground detail of padded training weapons, cape clasps, costume brushes, thread, and a prop cart beside the training ground. The background includes wardrobe racks and a few crew silhouettes.

## Key Frame

Claude is mid-pose with a prop bow as a prop master gently takes it away. Edelgard checks a cape clasp with precise focus. Dimitri holds a padded lance, testing its balance too seriously.

## End Frame

The prop master has the bow, Claude accepts it with a light expression, Edelgard's cape clasp is corrected, and Dimitri still studies the padded lance as if it were a real tactical matter.

## Identity Locks

Only soft or padded training weapons. Academy costumes. Claude remains charming, Edelgard controlled, Dimitri earnest.

## Reject If

Reject if weapons become sharp/lethal, if prop equipment overwhelms the fantasy setting, if Claude becomes clownish, or if costume details redesign the characters.

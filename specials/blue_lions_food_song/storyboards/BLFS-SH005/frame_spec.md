# BLFS-SH005 Frame Spec

## Shot Purpose

Pay off Felix's care through action and end with the plant-singing deadpan.

## Start Frame

Felix takes the watering can from Annette calmly, with the flower row visible.

## Key Frame

Felix waters the flowers carefully while staying as serious as he would in training.

## End Frame

Felix warns that the flowers may start singing if they are left thirsty; Annette reacts, embarrassed and indignant.

## Identity Locks

Felix is restrained and helpful without openly softening. Annette is bright, flustered, and academy-age.

## Reject If

Reject if Felix hums or performs the song, if the ending becomes too sentimental, or if the watering can changes shape or disappears.

# BLFS-SH001 Frame Spec

## Shot Purpose

Establish Annette's private greenhouse song and the step-turn-pour rhythm that Felix will later call footwork.

## Start Frame

Youthful academy Annette stands alone in a warm Garreg Mach greenhouse aisle, brass watering can in hand, checking that nobody is nearby. Flower shelves and a still-dry left row are visible.

## Key Frame

Annette sings the adapted English food-song line while watering flowers. Her feet make a tiny controlled step-turn-pour pattern, private and cheerful rather than staged.

## End Frame

Annette finishes the last sung phrase and turns toward the greenhouse doorway, still holding the watering can.

## Identity Locks

Annette: younger/cuter academy comedy variant, orange bangs, twin side buns, blue eyes, Blue Lions academy uniform, bright earnest student energy, not childish and not mature-adult.

## Reject If

Reject if Annette looks too old, if this reads as an idol performance, if musical effects appear, if the greenhouse is not readable, or if the left row is already watered.

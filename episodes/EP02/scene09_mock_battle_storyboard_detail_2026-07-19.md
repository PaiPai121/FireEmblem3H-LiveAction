# EP02 Scene09 模拟战详细分镜与关键帧设计

Date: 2026-07-19

原则：这场不是无序群架，也不是青狮碾压另外两个学级，而是“青狮正面压黑鹫、金鹿同时搅乱青狮后线和黑鹫侧线、黑鹫反压金鹿射击区、贝雷特把混乱窗口转化为青狮险胜”。所有镜头保持同一张户外模拟战地图的空间关系：青狮从东南进入，中线压向黑鹫，金鹿从林地侧后切入但不站队，东北高台为教师治疗与裁定位置。胜利条件是迫使 Hanneman 与 Manuela 离开治疗纹/教师裁定区，不是击倒同学。

背景母版：`assets/locations/EP02/act02/MockBattleGrounds_CanonMap/MockBattleGrounds_CanonMap_master_2026-07-19.png`。旧 `MockBattleGrounds_CanonMap_reference.svg` 只作为坐标示意。

硬方位规则：画面上方为北，右下为东南起点，左侧为西侧林地，右上为东北治疗高台。Blue Lions 从右下向中线/右上推进；Black Eagles 从北侧与右上纵深向南/西南抵抗；Golden Deer 从左侧林地向东/东南横切，同时压青狮支援线和黑鹫侧翼。Byleth 是轴线锚点，不追进西侧林地，而是把黑鹫往金鹿活动区挤，再切东北高台。

逐镜头朝向详表见：`episodes/EP02/scene09_direction_continuity_pass_2026-07-19.md`。

## 角色动作连续性

- Byleth：少说、短指令，永远在两条战线之间读局；动作是指向、拦截、切盲区，不靠个人乱杀赢。
- Dimitri：正面推进强，但必须被 Byleth 的手势收住；结尾枪尖停在 Hanneman 护具前，暗示内在危险。
- Dedue：盾线锚点，所有推进都围绕他能否把口子撑住。
- Felix：个人能力强，风险是脱队；中段被 Byleth 叫停，后段改为截住 Ferdinand。
- Ashe：从观察位被 Claude 压走，再重新抢半高点，最后压 Hanneman 施法角。
- Annette：从紧张到能用风魔法遮蔽金鹿射线。
- Mercedes：治疗不是大场面，短促、干净、让前排继续站住。
- Sylvain / Ingrid：右翼承接金鹿压力；Ingrid 负责切 Manuela 的回位路线。
- Edelgard / Hubert / Ferdinand：黑鹫不能显弱。Edelgard 稳线，Hubert 压林地，Ferdinand 截 Felix / 守石阶。
- Claude / Hilda：金鹿聪明搅两边，不做背景队伍；他们既切青狮后线，也压黑鹫侧翼，让两边阵型都变形。
- Hanneman / Manuela：教师高台是胜负目标，不是普通敌人。
